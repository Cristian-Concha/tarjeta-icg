# Tarjeta digital ICG

Sitio estático para la tarjeta digital de Cristian Concha Prieto. No requiere instalación, servidor ni servicios externos.

## Publicación en GitHub Pages

1. Descarga y descomprime el archivo ZIP.
2. Abre el repositorio `Cristian-Concha/tarjeta-icg` en GitHub.
3. Selecciona **Add file** → **Upload files**.
4. Arrastra **el contenido** de la carpeta descomprimida: `index.html`, `styles.css`, `script.js`, `cristian-concha-prieto.vcf` y la carpeta `assets`.
5. Selecciona **Commit changes**.
6. Espera uno o dos minutos y abre `https://cristian-concha.github.io/tarjeta-icg/`.

GitHub Pages debe estar configurado para publicar desde la rama `main` y la carpeta `/(root)`.

## Comprobación

En el teléfono, verifica que funcionen los botones **Save contact**, **Call**, **Email**, **Website** y que el código QR de WeChat se vea nítido.

No se ha incluido un código QR principal de la tarjeta. Créalo solamente después de confirmar que la dirección publicada abre correctamente.
